https://www.kaggle.com/datasets/rohiteng/amazon-sales-dataset

## How to Run

1. Download dataset from the link above
2. Upload it to Kaggle or local environment
3. Run the notebook: amazon_ml_analysis.ipynb
4. All results (tables and figures) will be generated automatically
